# TV IPTV playlist

One M3U for the home TV (TiviMate), rebuilt daily by GitHub Actions:

- [Free-TV/IPTV](https://github.com/Free-TV/IPTV), grouped by country
- [iptv-org](https://github.com/iptv-org/iptv) channels for Malaysia, Singapore, Korea and Indonesia, grouped under those country names

Playlist URL: `https://raw.githubusercontent.com/pochexxgt/tv-iptv-playlist/main/playlist.m3u`

Run the workflow by hand from the Actions tab to refresh it right away.
